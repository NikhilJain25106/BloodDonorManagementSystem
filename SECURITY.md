# Security Policy

## Supported Versions

We actively maintain and provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The LifeDrop project team takes the security of our application and users' data very seriously.

If you discover a security vulnerability within the Blood Donor Management System, please **DO NOT** open a public issue on GitHub. Instead, please report it privately:

1. **Email**: Send detailed information about the vulnerability to [help@lifedrop.org](mailto:help@lifedrop.org).
2. **Details to Include**:
   - Description of the vulnerability and its potential impact.
   - Exact steps or proof of concept (PoC) to reproduce the issue.
   - Any proposed fix or remediation, if available.
   - Your contact details for coordination.

## Security Handling Process

- **Acknowledgment**: You will receive an acknowledgment of your report within 48 hours.
- **Evaluation**: The maintainers will investigate the vulnerability and determine the severity.
- **Fix & Release**: A security patch will be prepared and tested.
- **Disclosure**: Once the patch is deployed and verified, a security advisory will be published, with credit given to the reporter (unless you prefer to remain anonymous).

Thank you for helping keep LifeDrop and our community secure!
